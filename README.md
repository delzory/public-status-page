# Delzory Status

**Service availability, maintenance notices, and incident updates for Delzory.**

[View status](https://status.delzory.com) · [Security policy](SECURITY.md) · [Contribution policy](CONTRIBUTING.md)

This repository contains the source for Delzory's public status page. Delzory
maintains the page internally; public contributions are not accepted.

## Service status

Customers can expand three service groups to see individual components and their
incident history.

| Service group | Components |
| --- | --- |
| Website | Homepage, Documentation, Blog |
| Account | Sign-in, Portal, Billing, Notifications |
| Support | Requests, Urgent Assistance |

Status reflects published incident updates. **Operational** means no active
incident is published for a component; **Under maintenance**, **Disrupted**, and
**Down** describe maintenance, degraded service, and outages. An empty incident
history does not establish historical uptime.

Use the RSS links in the page footer to follow all updates or a specific
component. Support status describes contact-channel availability. For service
or account assistance, use your existing Delzory support channel.
