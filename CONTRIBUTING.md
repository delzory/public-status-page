# Contribution policy

Delzory operates this public status page internally. **We do not accept public
pull requests, feature requests, translations, or other external contributions.**

This repository contains the source for the published status page. GitHub Issues
are disabled, and this repository is not a customer support channel. For service
or account assistance, use your existing Delzory support channel. Report suspected
vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Bug-report, feature-request, and pull-request templates are retained for
authorized maintainer use. Their presence does not open this project to public
submissions or change the contribution policy.

Authorized maintainers make changes through pull requests into `master`, review
preview deployments, and follow [Production checks](docs/production-checks.md)
before merging. Incident updates follow [Incident publishing](docs/incidents.md).
