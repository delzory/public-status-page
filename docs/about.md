# About Delzory Status

[← Repository overview](../README.md)

Delzory Status provides a public view of service availability, planned
maintenance, and known incidents. Visit [status.delzory.com](https://status.delzory.com)
for the published page.

## Find the service you need

Expand **Website**, **Account**, or **Support** to see the individual components
in that group. Select a component to view its incident history and available feed.
A group shows the most severe active incident affecting any of its components;
unaffected components retain their own status.

Support status describes whether a contact channel is available. It does not
indicate queue length or promise a response time. Notifications refers to account
email and service alerts, rather than a hosted email service.

## Understand an update

| Status | Meaning |
| --- | --- |
| Operational | No active incident is published for the component. |
| Under maintenance | An active maintenance notice affects the component. |
| Disrupted | A published incident describes degraded service. |
| Down | A published incident describes an outage. |

Incident posts explain the known impact, affected services, and progress toward
recovery. Resolved posts remain in the history. Times marked **UTC** use
Coordinated Universal Time; relative times indicate how long ago an update occurred.

## Follow changes

Use the RSS link in the page footer to subscribe to all incident updates. A
component's detail page also offers its own feed. Subscribing requires a feed
reader; it does not enroll you in email or SMS alerts.

## Know the limits

The page reflects incident records published by maintainers. It is not an
independent live test of each service, and an Operational label cannot rule out
an unreported or newly developing issue. The history begins with this launch;
an empty history is not a measurement of past uptime.

For a service problem that is not listed, use your existing Delzory support
channel. This GitHub repository is not a support queue, and GitHub Issues are
currently disabled. Report suspected vulnerabilities privately using the
[security policy](../SECURITY.md).
