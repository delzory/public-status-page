# Contribution policy

Delzory maintains this public status page internally. We do not accept public
pull requests, feature requests, translations, or other external contributions.

This repository is not a customer support channel. For service or account
assistance, use your existing Delzory support channel.

Report suspected vulnerabilities privately as described in
[SECURITY.md](SECURITY.md). Community conduct is covered by the
[Code of Conduct](CODE_OF_CONDUCT.md).
